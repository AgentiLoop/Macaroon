# Macaroon

A simple GUI app for running Mac, Windows and Linux virtual machines on Apple silicon, built on Apple's Virtualization framework. Pick a guest, click Download & Install, then Start: no command line needed. Runs macOS, Windows 11 ARM and Linux.

**Internal project — not available to the public.** Builds are for the team only; don't distribute them.

Version 1.4.

## Use

1. Open `Macaroon.xcodeproj` and run.
2. Pick a guest: **Mac** (macOS 26 and later), **BigMac** (macOS 12 up to 15), **Linux** or **Windows ARM**.
3. For macOS, choose a restore image from the list. The list comes from Apple's IPSW catalog (`mesu.apple.com`) and is filtered to `VirtualMac2,1` images; older releases back to macOS 12 come from ipsw.me (`api.ipsw.me`), and each one downloads to its own file in the VM folder.
4. Click **Download & Install**. This downloads the IPSW (about 17 GB) and installs macOS onto a 64 GB sparse disk.
5. Click **Start**, then finish macOS Setup Assistant inside the VM.
6. Drag any `.app` onto the window. It is copied to the shared folder, which macOS mounts inside the VM at `/Volumes/My Shared Files`.

VM files are stored in `~/Library/Application Support/Macaroon/<guest>` (`VM`, `BigMac`, `Linux`, `Windows`).

**More than one VM per guest:** the VM menu next to the guest picks which VM of that guest you use. The **+** menu makes a **New VM…** (empty, install it as usual) or a **Copy** of the current VM (an APFS clone of its disk, so it is instant and takes no extra space at first; it gets its own MAC address and snapshots). Each one gets a name you choose and lives in `<guest> 2`, `<guest> 3`, … next to the first.

**Sound:** every guest gets a virtio sound device: the Mac's speakers for output and its microphone for input (macOS asks for microphone permission the first time a guest records).

**Snapshots** (toolbar menu): Take Snapshot… asks for a name, then clones `Disk.img` and `AuxiliaryStorage` into `<guest>/Snapshots/<date> <name>/` using APFS copy-on-write, so it is near-instant and uses no extra space at first. If the VM is running, it is paused and its memory/device state is saved too, so restoring resumes exactly where it left off. Each snapshot can be renamed (Rename…). Restore first saves a "Before Restore" snapshot, so you can always go back.

**Start in Recovery** (macOS guests): boots the VM into macOS Recovery, e.g. to run `csrutil disable`.

**Windows 11 ARM** (needs `brew install wimlib`): pick Windows ARM, then Download & Install (or Install from ISO…). Macaroon repacks the ISO into `Windows/Media.img`, installs unattended through WinPE with the virtio-win drivers, and restarts the VM through Windows' reboots until setup is done (about 10 minutes). Log in as your Mac user name with password `macaroon`. Apple's firmware has no framebuffer for Windows, so a small UEFI driver supplies one (`Tools/WindowsEFI`, rebuild with `make`).

**Linux:** GPU OpenGL through VirGL (`Tools/VirGL`); in Ubuntu run `sudo sh "/mnt/Set Up 3D.sh"` once, then `macaroon-gl <app>`.

## Inspiration

Macaroon was inspired by [Hobo](https://hobo.gsquared.app) ([github.com/hobo-vm/hobo](https://github.com/hobo-vm/hobo)), Greg Galloway's command-line tool for ephemeral macOS, Linux and Windows VMs on Apple silicon. Thank you, Greg, for the inspiration and for your friendship.

Macaroon is an independent project and is not affiliated with or endorsed by Hobo. Apart from Greg's Windows 11 display-driver patch credited below, Macaroon contains no code from Hobo. Hobo is licensed separately under the Apache License 2.0; see its repository for details.

## Building

Regenerate the project with `xcodegen generate` after editing `project.yml`. The app icon is generated by `Tools/Icon/MacaroonIcon.swift`.
