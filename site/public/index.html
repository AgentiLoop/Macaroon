Every OS you need.
One sweet Mac app.

Run macOS, Windows 11 ARM and Linux virtual machines on Apple silicon, built on Apple's Virtualization framework. Pick a guest, click Download & Install, then Start. No command line needed.

Three kinds of guests. One window.

macOS

Install straight from Apple's restore images: Mac for macOS 26 and later, BigMac for macOS 12 up to 15. Start in Recovery to change settings like SIP.

Windows 11 ARM

An unattended install from Microsoft's ISO with the virtio-win drivers. Macaroon restarts the VM through Windows setup for you, about ten minutes start to finish.

Linux

Ubuntu ARM64 ISOs from the menu, or bring your own. Clipboard sharing, a shared folder, and optional GPU-accelerated OpenGL through VirGL.

Snapshots

APFS copy-on-write snapshots are near-instant and take no extra space at first. A running VM's memory is saved too, so a restore resumes right where you left off.

Many VMs, instant copies

Keep more than one VM per guest. A copy is an APFS clone of the disk with its own MAC address and snapshots.

Drag an app in

Drop any app on the window and it lands in the shared folder, mounted in a Mac guest at /Volumes/My Shared Files. Sound and microphone work in every guest.

Up and running in three steps.

  1. Download the ZIP, unzip it, and move Macaroon.app to Applications.
  2. Pick a guest (Mac, BigMac, Linux or Windows) and a restore image or ISO from the menu.
  3. Click Download & Install, then Start. VMs live in ~/Library/Application Support/Macaroon.
Good to know.

macOS installs download about 17 GB and use a 64 GB sparse disk. Windows 11 ARM needs brew install wimlib and has been tested on a Mac running macOS 27.2.1.
